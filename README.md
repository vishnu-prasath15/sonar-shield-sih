# SONAR SHIELD — Marine Debris & Anomaly Intelligence

**SONAR SHIELD** is an advanced marine intelligence platform designed for acoustic sonar imagery analysis, automatic marine debris detection, seafloor hazard classification, and interactive mission mapping.

Built for the **Smart India Hackathon (SIH)** marine surveillance and ocean cleanup initiatives.

---

## 🌊 Key Features

- **Acoustic Sonar Workspace**: High-resolution side-scan and forward-looking sonar visualizer with real-time copper, thermal, emerald, and grayscale acoustic palettes.
- **AI Anomaly Detection Pipeline**: Computer vision and acoustic backscatter inference pipeline for identifying underwater debris, sunken hazards, lost fishing gear, pipeline anomalies, and natural seabed structures.
- **Interactive Marine GIS Map**: Geospatial survey tracking with anomaly heatmaps, bathymetric overlays, vessel trajectories, and mission waypoints.
- **Verification & Review Queue**: Human-in-the-loop expert validation dashboard with confidence scoring, re-classification tools, and audit trails.
- **Survey Reports & Analytics**: Automated mission reporting with area coverage metrics, density statistics, exportable survey summaries, and sensor calibration metrics.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS + Lucide Icons
- **Design System**: Marine acoustic theme with responsive and accessible UI components

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/vishnu-prasath15/sonar-shield-sih.git

# Navigate to project folder
cd sonar-shield-sih

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```
